# 신학 문답

확정한 서재 디자인을 사용하는 기독교 질문·묵상 홈페이지입니다.

- 홈페이지: https://theology-qa.vercel.app
- GitHub: https://github.com/MoonSo0209/theology-qa
- 온라인 기본 모드: 실제 AI 답변 / 로컬 기본 모드: 예시 답변

## 폴더 구성

- index.html: 홈페이지
- assets/: 디자인, 화면 동작, 예시 콘텐츠, 공통 대화 처리
- api/ask.js: Gemini 연결과 질문 처리
- local/시작.cmd: 로컬 홈페이지 실행
- tests/: 외부 AI를 호출하지 않는 검증
- backups/before-study-design-20260907-215642/: 변경 전 파일과 디자인 시안, Git 이력 백업 (GitHub와 배포에서 제외)

## 기능

큐티·고민·삶·교리의 색상을 구분하고, 스크롤 중 질문 발췌와 본문 위치를 고정합니다.
신학자 견해, 용어 풀이, 관련 성경 구절·인물 등 기존 구성을 유지합니다.
이어서 질문하기는 최근 3개 질문과 답변의 핵심 발췌를 참고 맥락으로 전달합니다.
기존 서버의 1,000자 제한에 맞춰 새 후속 질문은 700자까지 받으며, 남은 공간에 맞춰 이전 발췌를 줄입니다.
대화는 브라우저 메모리에만 유지하며 새로 고침하면 사라집니다. 갈래별 맥락을 분리하고 모드를 바꾸면 연결을 해제합니다.
예시 모드의 후속 답변도 준비된 예시입니다. 새 연계 답변은 실제 AI 모드에서 생성됩니다.

## 로컬 실행

local/시작.cmd를 실행하면 http://127.0.0.1:4187 에서 확인합니다.
index.html을 직접 열어도 예시 모드를 이용할 수 있습니다.
로컬에서 실제 AI를 선택하면 운영 홈페이지의 API에 연결하여 사용량이 소모됩니다.

## 배포와 복구

Vercel과 연결된 GitHub main 브랜치로 푸시하면 자동 배포됩니다.
GEMINI_API_KEY는 Vercel 환경변수에만 저장하며 기존 모델과 대체 모델 설정을 유지합니다.
백업 폴더는 로컬에만 보관합니다. 백업 파일 또는 Git 이전 커밋으로 복구할 수 있습니다.
백업의 repository-history.bundle에는 변경 전 Git 이력이 들어 있습니다.

검증: node --test tests/release.test.cjs
